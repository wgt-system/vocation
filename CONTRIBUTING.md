# Contributing

Normal development happens on `dev`. `main` contains stable, versioned milestone releases only.

Run the relevant tests while developing and run `scripts/check.ps1` before merging a milestone into `main`. Issues describe planned work; they do not require one branch per issue. Feature branches are optional for parallel work or risky isolated experiments.

Never commit personal job-search data, local databases, prompts, logs, credentials, or other private files. Keep commit messages concise and descriptive.
