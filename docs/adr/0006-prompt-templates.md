# ADR-0006: Versionierte Prompt Templates

**Status:** Accepted

## Entscheidung

Vocation verwaltet versionierte Prompt Templates für Initial-, Update-, Teilupdate-, Gap-Filling- und Availability-Recherche.

## Konsequenzen

- Prompt Runs werden nachvollziehbar,
- Research Bundles können einem Prompt Run zugeordnet werden,
- der Nutzer kopiert manuell,
- keine LLM-API-Kosten.
