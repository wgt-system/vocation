# ADR-0002: Research Bundle als Published Language

**Status:** Accepted

## Entscheidung

Rechercheergebnisse werden über ein versioniertes JSON Research Bundle übergeben.

## Konsequenzen

- JSON Schema und Beispiele sind verbindlich,
- Anticorruption Layer übersetzt in das Domain Model,
- direkte LLM-API ist nicht erforderlich,
- Vertrag muss versioniert werden.
