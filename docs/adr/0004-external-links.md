# ADR-0004: Originalanzeigen werden im Standardbrowser geöffnet

**Status:** Accepted

## Entscheidung

Vocation darf validierte Posting-URLs nach expliziter Nutzeraktion im Standardbrowser öffnen.

## Konsequenzen

- Pin-Klick allein öffnet keine externe Seite,
- mehrere Quellen müssen auswählbar sein,
- nur erlaubte URL-Schemes,
- Browserfehler werden sichtbar behandelt.
