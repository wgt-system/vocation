# ADR-0001: Vocation bleibt eigenständig ausführbar

**Status:** Accepted

## Entscheidung

Vocation ist ein eigenständiges Projekt, besitzt eigene Datenhaltung und kann ohne Wiiii Got This gestartet und genutzt werden.

## Konsequenzen

- keine WGT-Laufzeitabhängigkeit,
- spätere Integration nur über veröffentlichte Verträge,
- Desktop UI gehört zu Vocation,
- eigene Versionierung und Auslieferung.
